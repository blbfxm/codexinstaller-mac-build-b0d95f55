使用本插件的 `jianguo_image` MCP 工具完成生图，不调用 OpenAI 的生图接口或其他供应商。

1. 用户必须明确指定生图模型 ID，例如 `nano-banana-2`。未指定时先询问；需要查看可用模型时调用 `list_image_models`，展示模型名称、ID 与价格，不将列表首项作为默认模型。价格和可用性以平台返回与卡密所属分组为准。
2. 组织用户要求的提示词。使用 `generate_image`，传入 `model`、`prompt`、`outputFile`（当前项目中图片保存位置的绝对路径）；仅根据用户需要传入 `aspectRatio`、`imageSize`、宽高、质量、透明背景和参考图。`images` 可用本机图片绝对路径或合法图片 data URL。参考图会上传到坚果平台用于处理。
3. 凭证由插件从本机安全存储读取，不询问或打印 API Key，不把凭证写进提示词、命令、项目文件或对话。提示凭证缺失时，让用户到 Codex 使用助手的“插件”中更新凭证。
4. `generate_image` 返回 `jobId` 后，用 `get_image_result` 查询同一个任务。尚未完成时等待约 3 秒再查，最长等待 10 分钟。提交与查询分开；网络超时、断线或结果暂未可用时，不重新调用 `generate_image`。生图可能已计费，重复提交会产生新的费用。保留任务 ID，稍后继续查询；任务明确失败后按返回的原因告知用户。
5. 成功后使用返回的绝对文件路径展示图片，并告知所用模型和保存位置。结果保存在本机，重复查询会复用已保存的图片。不要声称图片已经生成，直到工具返回 `completed` 和真实文件路径。

生成请求使用 `POST /api/v1/generate`，凭证放在 JSON 的 `kami` 字段中。插件负责处理任务轮询或直接图片地址；不要改用对话接口、Bearer 认证或手工拼接带密钥的 URL。插件安装免费，实际生成按坚果平台相应模型价格扣点。
