# 账户、微信连接与本机用量

## 账户

- 登录页可使用邮箱注册：图形验证码 → 邮箱验证码 → 设置密码 → 注册并登录。
- 账号密码登录使用 `/api/v1/account/login-password`，兼容原有安装助手账号。
- 个人中心的 API Key 默认隐藏；没有 Key 时显示“添加 API Key”。网页账户中心位于个人中心右上角。
- 一键安装并配置优先使用当前账户已有 API Key；没有时调用 `POST /api/v1/installer/codex-api-key`，请求带 `X-Client: codex-assistant`、账号及 SHA-256 密码摘要。该接口在后台负责复用或创建主 Key。
- 密码摘要仅保存在原生进程本次登录的内存中，退出登录清除。验证码、账户会话 Cookie 和 CSRF 标识由原生进程维护。
- 如果服务器启用了共享助手令牌，部署环境需提供 `CODEX_ASSISTANT_TOKEN`；客户端不内置服务端密钥。

## 微信连接

1. 在助手中安装 Codex 并配置可用供应商。
2. 打开左侧“微信连接”，选择本机项目文件夹。
3. 获取连接二维码，使用个人微信扫码并确认。
4. 默认只读；需要修改项目文件时，自行勾选“允许修改项目文件”。
5. 开启连接后，在微信对应会话发送文字。`/new` 新建会话，`/help` 查看帮助。

Windows 使用由助手主窗口拥有的原生文件夹选择窗口，不再启动 PowerShell 对话框。选择文件夹、读取状态和获取二维码独立处理；等待扫码时仍可选择工作目录。未绑定时点击“开启微信连接”会引导扫码，确认后自动开启连接。

二维码获取含响应正文有 12 秒超时，可取消、刷新或在网络恢复后重试；取消后返回的旧二维码和扫码结果不会覆盖新请求。切换页面会取消未完成的扫码，不停止已经开启的连接。

微信会话通过 Codex 自带的本机会话程序运行，使用当前 Codex 配置，无需 Codex++。支持文字和已经转成文字的语音；本版不处理图片及文件。一次任务最多等待 10 分钟。

只接收扫码绑定者的消息。令牌、轮询游标及已处理消息标识使用 Windows DPAPI 或 macOS 钥匙串保存，不将授权令牌发送给页面。消息在执行前记录为已处理，避免进程重启重复执行同一个任务；执行中断后可重新发送新消息。

切换页面或最小化不停止连接；停止连接、解除绑定、退出登录及退出助手会停止接收并结束本功能启动的 Codex 会话进程。关闭窗口进入托盘，因此仍可接收消息。模型请求按当前供应商规则计费。

## 本机用量

个人中心 → 用量，选择当天、7天、30天、全部。统计本机 `CODEX_HOME/sessions` 与 `archived_sessions` 中的 JSONL 计数记录，按本机时区划分自然日，支持按日趋势及按模型汇总。

“用量统计”与“使用日志”独立呈现。使用日志按时间倒序每页显示 20 条，包含模型、输入、缓存、输出及总 Token；详情显示会话 ID、已记录的请求 ID 和推理 Token。切换时段回到第一页，未记录请求 ID 时显示“本机未记录”。没有写入本地用量记录的失败请求不包含在内，日志也不代表服务器 HTTP 访问日志或扣费账单。

输入 Token 已包含缓存输入；输出 Token 已包含推理 Token；总量为输入加输出，不重复累计缓存或推理子项。对同一会话的累计计数做差分，重复记录不重复计入。计数缺失、重置、受损或压缩档案未读取时标明统计不完整，不将历史累计数全部归入今天。

此页汇总本机 Codex 会话，包含不同供应商，不是当前坚果账户的扣点账单。不会将本地提示词、回复或工具输出上传到平台。

## 验证

- `npm run build`
- `cargo test --manifest-path src-tauri/Cargo.toml --lib`
- `node scripts/check-account-wechat-usage.cjs`（Windows Edge、Node 22+；使用模拟账户及微信接口）

界面测试覆盖 20/20/5 条分页、时段切换、深浅主题和不同窗口宽度；二维码等待期间按钮独立响应、取消、旧响应忽略和失败后重试；自定义供应商名称、Base URL、API Key 及默认模型为空，编辑已有供应商保留原值。

二维码接口可直接连通验证；真实微信扫码授权及完整模型回复需要在用户微信完成扫码后验收。自动测试不会创建真实账户、发送注册邮件或调用付费模型。
