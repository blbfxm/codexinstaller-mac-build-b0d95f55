# Codex 安装位置

Windows 的“安装配置选项”中可选择 Codex 安装磁盘，选择后自动保存。官方 MSIX 使用 Windows 管理的应用存储目录，例如 D:\WindowsApps，不能指定任意普通目录。

一键安装、单独安装及微软商店安装入口均先等待设置保存，并由后端重新读取设置。有指定磁盘时，商店入口改用支持按应用指定目标磁盘的官方 MSIX 安装流程，不修改系统默认安装磁盘。目标磁盘离线或不可用时明确提示，不静默装到 C 盘。已安装的 Codex 仍按原规则跳过安装，修改设置不会自动迁移已安装应用。

配置保存于助手 app_config_dir 下 codex-install-location.json，与 Codex 的会话、模型和权限配置分开。

验证使用隔离的 PowerShell 模拟环境：默认安装、指定现有卷、新建卷授权、必要时移动本应用、磁盘离线及移动失败等情形均覆盖；未在开发机实际安装、迁移或修改默认 Appx 卷。
