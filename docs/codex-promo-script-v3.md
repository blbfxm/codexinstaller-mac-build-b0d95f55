# 《Codex 能帮你做什么？我们能做什么》文案与制作方案 V3

本稿合并用户提出的六项修改，作为确认后的制作依据。目前仍为文案与方案阶段，尚未开始配音和视频渲染。

## 已确定的要求

- 标题：《Codex 能帮你做什么？我们能做什么》。片头可以分两行排版，文字不改。
- 开场覆盖办公、运营、内容和开发需求；开发不再以“做个网页”为主要诉求。
- 旁白和营销字幕不提“Codex 使用助手”，服务统一称为“我们提供一键式部署配置与使用方案”。
- 用户无需录屏、配音或操作剪映。素材搜索、界面素材生成、配音、字幕、动画、剪辑、合成和检查由 Codex 自动处理。
- 宽高比 1:1。主交付 3840×3840、30fps、H.264 MP4；另输出 2160×2160 兼容版，便于上传。母版文字与图形按目标分辨率直接渲染；外部低分辨率视频用局部展示和版式承载，不能把放大称作真实细节提升。
- 上一轮所有宣传口径边界已获用户同意，继续执行。
- 默认约 170 秒，按自动配音的实际时长和素材质量微调，不以固定时间挤压可读性。
- 配音默认自然、清晰、偏中性的中文讲解声；音乐轻量；全程简体中文字幕。风格和工具由 Codex 选择，用户无需逐项决定。

## 一、定位

面向需要提升日常工作效率、处理复杂资料、开发工具或推进项目的人群。用具体工作成果解释 Codex 的价值，再介绍我们如何帮助客户部署与上手。

不把客户限定为电商用户；电商销售分析保留为数据处理的一个例子。整体结构为：更广的需求入口 → 文件与数据 → 文档与内容 → 自动化 → 开发与维护 → 技能与项目管理 → 部署服务与赠品 → 咨询引导。

## 三、全自动制作方式

1. 搜集可用于本视频的网络演示素材，记录来源、片段用途、版本、可获取性和许可条件。官方公开发布并不自动意味着允许商用；未取得合适许可的素材用作参考，改用自制画面。
2. 从本项目生成界面素材，并使用用户已有的 Codex 截图。用局部放大、步骤切换和光标动效讲解安装流程。用户不需要操作应用或补录画面。
3. 使用程序调用中文 TTS 自动生成旁白，按句记录音频时长，再据此安排画面与字幕。优先评估可编程的自然语音服务；本机 Windows 已检测到中文语音，可作本地备选。尚未测试最终配音音质或网络 TTS 可用性，不预先承诺某个服务一定可用。
4. 使用 Remotion 编排方形场景、字幕和信息卡，必要时使用程序生成高分辨率图形。合成、裁切、混音和编码使用 FFmpeg 完成，不依赖用户操作剪映。
5. 自动导出后检查分辨率、比例、时长、音轨和字幕安全区域，并抽帧检查文字清晰度、排版和画面内容；核对配音与字幕同步及关键宣传表述。

可先自动生成 15–20 秒内部样片完成技术验证，再继续全片；若用户已授权制作，不再因工具、配音风格或中间环节反复请求确认。最终提供成片与可修改的工程、文案、字幕及素材来源记录。

## 四、清晰度与交付

- 主版：3840×3840，1:1，30fps，H.264 MP4，AAC 音频。
- 兼容版：2160×2160，1:1，30fps，H.264 MP4。
- 字幕：嵌入画面的简体中文字幕；同时保留独立 SRT。
- 画面：标题与主要文字留在安全区域；软件界面按重点局部展示，避免完整桌面缩小导致文字看不清。
- 外部素材：优先高分辨率、少压缩的来源。达不到母版清晰度的片段缩小展示，并配合原生清晰字幕和图形；不承诺低分辨率素材经放大能恢复真实细节。
- 规格若受投放平台限制，可从母版自动导出适配版本，不要求用户操作编码工具。

## 五、宣传口径（用户已全部同意）

- 原版客户端与接入服务分开表述：原版 Codex 客户端、本店部署配置服务、本店模型服务额度。
- 不使用“全部功能解锁”“官方赠送额度”“官方会员权益”等未经证实的表述。
- “满配启动”在项目中对应启动时准备网络连接，不代表全部官方能力或套餐权益。网络服务按实际套餐说明，不默认宣传为免费或已包含。
- 技能库为整理与安装服务；公开社区技能不称作自研独家。
- 初始赠送额度、有效期与教学视频清单按实际套餐履约，不编造数字或承诺。没有具体数额时统一写“随套餐赠送初始使用额度”。
- 文档、表格、演示、插件和定时任务等能力按相应技能、工具、账号及环境条件表述。外部视频不能直接证明本店模型通道具有相同权益。
- 首版项目服务展示以 Windows 界面为主；macOS 的测试与交付待办按 README 执行。
- 不承诺固定秒数装好、永久免费、无限额度或所有任务一次成功。加速过程标注“过程已加速”。
