# Codex 宣传视频文案与制作方案 V2

状态：供确认的首稿；本阶段只交付文案与制作方案，不录制、不配音、不渲染视频。

用户补充：无法自行录屏。制作方案调整为网络演示素材、本项目界面截图与动效、成果示意和中文旁白组合，不要求用户录屏。网络素材的具体片段、获取方式和商用授权仍待核实；尚未取得可直接用于成片的外部视频。

## 一、定位与传播目标

- 默认用途：淘宝商品详情页、客服介绍素材；确认后可另剪短视频引流版。
- 核心客户：电商运营、办公人群、个体创业者；兼顾需要开发工具、维护网站的用户。
- 主张：把需求说清楚，让 Codex 帮你把事情做出来。
- 内容顺序：工作痛点 → 实际成果 → Codex 能力 → 我们的部署与赠品 → 行动引导。
- 建议长度：约 160 秒，以配音试读为准。功能和成果约占 70%，安装服务与赠品约占 30%。
- 建议标题：《整理报表、批量处理文件、做网页：Codex 能帮你做什么？》
- 封面短句：把需求说出来，把成果做出来。

## 三、推荐制作方法与工具

采用“可获授权的网络演示视频 + 本项目界面动效 + 成果示例 + 中文旁白”的方法。暂按约 40% 网络功能演示、35% 项目界面与成果展示、25% 字幕与信息卡设计，最终比例由可用素材决定。用户无需录屏。

上方分镜中的“实录”统一调整为：Codex 通用功能段优先寻找可获授权的对应演示；安装助手段根据本项目界面制作截图切换、局部放大和流程动画。没有真实视频的步骤用清楚标注的流程示意呈现。

| 环节 | 工具 | 具体做法 |
| --- | --- | --- |
| 网络素材筛选 | 官方发布渠道、授权素材库、明确许可的创作者视频 | 按功能查找片段，记录来源、对应版本、分辨率和许可条件。公开可观看不等于可用于商业宣传，官方素材也须核对使用条款。许可不明确的片段只作为创作参考。 |
| 本项目画面 | 现有截图、项目界面、Remotion | 使用用户已有 Codex 截图；后续可从本项目页面自行生成安装助手界面图片，配合光标、步骤切换和局部放大。模拟状态明确标注，不要求用户补录。 |
| 成果示例 | 示例表格、文稿、网页及文件目录 | 自制与旁白匹配的示例成果，展示前后变化；数据人工核对，不把自制示例称作未经验证的 Codex 实际输出。 |
| 包装与合成 | Remotion | 排列镜头、重点区域放大、关键词字幕、赠品卡和结尾引导；文案和卖点可集中修改。后续独立建视频目录，不改安装器业务代码。 |
| 配音 | 真人录音，或剪映中文配音 | 语气自然、清楚，约每分钟 240–280 个汉字。先做试读，统一 Codex 读法，再锁定镜头时长。 |
| 声音与交付检查 | 剪映，必要时 FFmpeg | 配音优先，音乐低于人声；检查字幕同步、字体和音量，导出 MP4。Remotion 也可直接完成最终合成。 |

主版建议 16:9、1920×1080、30fps、H.264 MP4，适合展示桌面软件和商品详情。若需要竖版，另排版成 1080×1920：重点区域放大，上下区域承载标题和字幕，不能直接把完整桌面缩小塞进去。平台规格在正式输出前确认。

视觉风格沿用现有 Codex 的白底、深灰文字，以及安装助手的绿色点缀。少用装饰性转场，每个功能至少给成果 2–3 秒的清晰展示。用户提供的截图作为界面参考和可选静态素材，不作为功能已经跑通的证明。

## 四、确认后的制作顺序

1. 根据客户和投放位置修订旁白，确定套餐权益、赠送额度和教程清单。
2. 整理网络视频候选清单及片段用途，核实授权、获取方式和画质；依据可用素材修订分镜。没有合适素材的场景采用明确标注的界面或流程示意。
3. 先完成开头和一个功能场景的 15–20 秒样片，确认节奏、配音和视觉风格。
4. 完成获准素材剪辑、项目界面动效与全片合成，提供带字幕预览。
5. 按反馈修改后输出正式横版；需要时再制作短版或竖版。

## 五、与当前项目对应的宣传口径

以下是代码阅读确认的实现范围，并不等同于对客户机器完成验收：

- `src/main.ts` 有一键安装配置、简体中文、完整访问权限选项、可选 Codex++、供应商配置、技能库和个人中心入口。
- `src-tauri/src/lib.rs` 有 Windows Codex MSIX 安装、已安装检测、模型配置和技能安装实现；Windows 备用安装包使用官方静态资源域名。
- 技能库聚合 Codex++ 与 Composio 社区目录，支持中文分类和按需安装。宣传为“赠送整理与安装指导”，不把公开社区资源说成自研独家技能。
- 个人中心有余额、用量和充值相关实现。未在本项目中看到自动赠送初始额度或教学视频发放的完整实现；这两项按用户提出的套餐交付意向写入首稿，发布前要落实具体数额和内容。
- 代码中的“满配启动”是启动时准备网络连接，有独立计费说明，不代表解锁全部模型、官方会员或所有插件。主旁白建议使用“安装与常用配置一次准备”，不使用无边界的“全部功能解锁”。
- 原版客户端与接入服务分开表述：原版 Codex 客户端 + 本店部署配置服务 + 本店提供的模型服务额度。不要写成 OpenAI 官方店铺、官方赠送额度或官方会员权益。
- 文档、表格、演示文稿等能力依赖相应技能、运行工具及模型能力；部分插件、云端或定时能力也可能取决于账号和环境。网络视频证明的是其来源环境的演示，不能直接证明本店交付通道具有同样权益；套餐承诺须以实际交付环境验证为准。
- README 将 macOS 包标记为测试交付范围，包含签名和实机验收待办，因此本项目安装段以 Windows 界面为主，暂不主推“双平台即装即用”。
- 不承诺固定秒数装好、永久免费、无限额度或所有任务一次成功。压缩录屏等待过程时标注“过程已加速”，不把加速片段当真实耗时。
